# EPINET reflection masks

The three unmodified PNG files were downloaded from the official chshin10/epinet repository on 2026-09-08:

https://github.com/chshin10/epinet/tree/master/hci_dataset/additional_invalid_area

Each scene uses `input_Cam040_invalid_ver2.png`; alpha > 0 denotes invalid reflection pixels. `LICENSE` is the repository MIT license. `DATA_LICENSE.txt` is the HCI dataset attribution/license notice from the same repository. No masks are applied to public validation scenes.
